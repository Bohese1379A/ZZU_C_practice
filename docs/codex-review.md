## 题意处理 / Exercise decisions

- 题目依据仓库原实验资料。本分支保留资料文件，也保留实验一至实验九及实验十一的目录。原资料没有提供实验十，未补写题目。
- 实验五第 3 题的示例首项为 1，通项代入该项会得到 1/2。程序采用题面列出的首项 1，从第 2 项开始用通项，并计入第一项绝对值小于 `1e-5` 的项。
- 实验六第 5 题未指定有限项数，保留原代码计算前 100 项的约定。实验六第 3 题的三个图形对应文件 `6_3.c` 至 `6_5.c`，后续文件编号与题号因此不同。
- 实验九第 1 题按阶乘写法限制 `0 <= m <= n <= 20`；实验十一第 8 题保留重叠匹配，例如 `aaaa` 中的 `aa` 有 3 次。
- 课程资料和旧版发布包的内容未改动。仓库未声明第三方课程资料的再发布许可。
